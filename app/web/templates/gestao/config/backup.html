3. Exportar dados em CSV

Um pacote .zip com os dados em planilha, para abrir no Excel, conferir contagens ou prestar informação. Não restaura o sistema — para isso é o backup acima. O servicos.csv sai no mesmo formato que a tela Importar histórico lê: é por ele que se leva o passado para uma instalação nova.

Desmarcado, o arquivo sai sem dado pessoal — é o padrão porque ZIP de planilha viaja em pen drive e anexo de e-mail com facilidade demais.
